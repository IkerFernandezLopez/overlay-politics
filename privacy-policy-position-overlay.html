Position Overlay

Política de Privacidad

Última actualización: 1 de octubre de 2026

Position Overlay procesa únicamente los datos necesarios para mostrar al usuario información de sus posiciones de Bitunix mediante un overlay en el navegador. No vende datos personales, no los utiliza para publicidad y no recopila el contenido de las páginas web que visita el usuario.

1. Responsable y ámbito de esta política

Esta política explica cómo la extensión de Chrome Position Overlay ("la extensión") trata los datos necesarios para prestar su funcionalidad.

Para cualquier consulta relacionada con privacidad puedes contactar con el desarrollador en kirikuri.dev@gmail.com.

2. Datos que procesa la extensión

La extensión puede procesar las siguientes categorías de datos:

  • Información de autenticación: credenciales o claves API de Bitunix proporcionadas voluntariamente por el usuario para autenticar las solicitudes a Bitunix.
  • Información financiera: datos devueltos por la API de Bitunix necesarios para mostrar la funcionalidad de la extensión, como posiciones abiertas, PnL, margen, tamaño de posición, apalancamiento, precio de entrada y niveles de Take Profit y Stop Loss.
  • Preferencias de la extensión: ajustes del overlay como tamaño de letra, opacidad, color del tema y estado de visualización.

3. Cómo se obtienen los datos

Las credenciales API y las preferencias son introducidas o configuradas por el propio usuario. La información de posiciones y cuenta se obtiene mediante solicitudes a la API de Bitunix cuando es necesario actualizar la información mostrada por el overlay.

4. Finalidad del tratamiento

Los datos se utilizan exclusivamente para proporcionar la función principal de Position Overlay: mostrar al usuario información de sus posiciones de Bitunix mientras navega.

La extensión no utiliza estos datos para publicidad, creación de perfiles publicitarios, reventa de datos, evaluación crediticia ni otros fines ajenos a la funcionalidad declarada.

5. Almacenamiento local

Las credenciales API de Bitunix y las preferencias necesarias para el funcionamiento de la extensión se almacenan localmente en el navegador mediante las APIs de almacenamiento de Chrome.

Position Overlay no utiliza este almacenamiento para crear un historial de navegación ni para registrar la actividad del usuario en las páginas que visita.

6. Transmisión y compartición de datos

Las credenciales necesarias para autenticar las consultas y los datos relacionados con la cuenta se transmiten a Bitunix únicamente en la medida necesaria para realizar las solicitudes a su API y devolver al usuario la información que solicita.

Position Overlay no vende, alquila ni comparte los datos del usuario con anunciantes, intermediarios de datos u otros terceros para fines comerciales o publicitarios.

Los datos solo podrían divulgarse adicionalmente cuando fuese necesario para cumplir una obligación legal aplicable o para proteger la seguridad e integridad del servicio, en la medida permitida por la ley.

7. Contenido de páginas web e historial de navegación

Position Overlay necesita ejecutarse sobre páginas web para poder mostrar su interfaz flotante. Este acceso se utiliza para insertar y mostrar el overlay.

La extensión no recopila ni almacena el historial de navegación del usuario, las URL visitadas, el texto, imágenes, formularios, mensajes u otro contenido de las páginas web sobre las que se muestra el overlay.

8. Seguridad

Las comunicaciones externas de la extensión se realizan mediante conexiones seguras HTTPS. La extensión limita el uso de datos personales y sensibles a lo necesario para proporcionar sus funciones visibles al usuario.

El usuario debe proteger sus credenciales API y conceder únicamente los permisos de Bitunix que sean necesarios para utilizar la extensión.

9. Conservación y eliminación

Las preferencias y credenciales almacenadas localmente permanecen en el navegador mientras sean necesarias para utilizar la extensión o hasta que el usuario las elimine.

El usuario puede eliminar los datos almacenados localmente borrando la configuración de la extensión o desinstalando Position Overlay de Chrome.

10. Uso limitado de los datos

El uso de los datos obtenidos a través de Position Overlay se limita a proporcionar o mejorar la funcionalidad visible y declarada de la extensión. Los datos no se utilizan ni transfieren para publicidad personalizada, retargeting o publicidad basada en intereses.

El desarrollador no permite el acceso humano a información financiera o de autenticación del usuario, salvo cuando sea estrictamente necesario por motivos de seguridad, cumplimiento legal o a petición expresa del propio usuario para resolver una incidencia concreta.

11. Servicios de terceros

La extensión se integra con la API de Bitunix para obtener la información solicitada por el usuario. El tratamiento que Bitunix realice de los datos recibidos está sujeto a sus propias condiciones y políticas.

Position Overlay es un proyecto independiente y no está afiliado, patrocinado, respaldado ni desarrollado por Bitunix.

12. Cambios en esta política

Esta política podrá actualizarse si cambia el funcionamiento de la extensión, los datos que procesa o los requisitos legales aplicables. La fecha de la última actualización aparecerá al principio de esta página.
