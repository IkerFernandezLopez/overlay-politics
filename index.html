Position Overlay

Política de Privacidad

Última actualización: 1 de octubre de 2026

Position Overlay procesa únicamente los datos necesarios para mostrar al usuario información de sus posiciones de Bitunix mediante un overlay en el navegador. La extensión no vende datos de los usuarios, no los utiliza con fines publicitarios y no recopila el contenido de las páginas web visitadas.

1. Responsable y ámbito de esta política

Esta política de privacidad explica cómo la extensión de Chrome Position Overlay ("la extensión") procesa y utiliza los datos necesarios para proporcionar sus funcionalidades.

Para cualquier consulta relacionada con privacidad puedes contactar con el desarrollador en kirikuri.dev@gmail.com.

2. Datos que procesa la extensión

Position Overlay puede procesar las siguientes categorías de datos:

  • Información de autenticación: credenciales API de Bitunix proporcionadas voluntariamente por el usuario y necesarias para autenticar las solicitudes realizadas a la API de Bitunix.
  • Información financiera: información obtenida desde la API de Bitunix relacionada con la cuenta del usuario, incluyendo posiciones abiertas, PnL, margen, tamaño de posición, apalancamiento, precio de entrada y niveles de Take Profit y Stop Loss.
  • Preferencias de la extensión: configuración del overlay, como tamaño de letra, opacidad, color del tema y estado de visualización.

3. Cómo se obtienen los datos

Las credenciales API de Bitunix son introducidas directamente por el usuario en la extensión.

Las preferencias del overlay son configuradas por el propio usuario.

La información financiera y de posiciones se obtiene directamente desde la API de Bitunix mediante solicitudes realizadas por la extensión cuando es necesario actualizar la información mostrada en el overlay.

Position Overlay no obtiene esta información desde otras fuentes.

4. Finalidad del tratamiento

Los datos se procesan exclusivamente para proporcionar la funcionalidad principal de Position Overlay: permitir que el usuario consulte información relacionada con sus posiciones de Bitunix mientras navega por otras páginas web.

Los datos no se utilizan para:

  • publicidad;
  • publicidad personalizada;
  • creación de perfiles publicitarios;
  • venta o reventa de información;
  • evaluación crediticia;
  • marketing;
  • análisis de comportamiento de navegación.

5. Almacenamiento de datos

Las credenciales API de Bitunix y las preferencias necesarias para el funcionamiento de la extensión se almacenan localmente en el navegador mediante las APIs de almacenamiento de Chrome.

Las credenciales API se utilizan únicamente para autenticar o firmar las solicitudes necesarias para comunicarse con la API de Bitunix.

Position Overlay no utiliza el almacenamiento del navegador para crear perfiles de usuario, registrar la actividad de navegación o mantener un historial de los sitios visitados.

6. Comunicación con Bitunix y transferencia de datos

Position Overlay se comunica directamente con los servicios de Bitunix mediante conexiones HTTPS.

Para realizar estas consultas, la extensión utiliza los datos de autenticación requeridos por la API de Bitunix. Bitunix devuelve a la extensión la información de cuenta y posiciones necesaria para mostrar las funcionalidades del overlay.

Los datos obtenidos desde Bitunix se utilizan exclusivamente para mostrar las funciones solicitadas por el usuario.

Position Overlay no transmite las credenciales API ni la información financiera del usuario a servidores operados por el desarrollador.

Position Overlay no vende, alquila ni comparte los datos del usuario con anunciantes, intermediarios de datos u otros terceros para fines comerciales o publicitarios.

7. Contenido de páginas web e historial de navegación

Position Overlay necesita ejecutarse sobre las páginas web visitadas por el usuario para insertar y mostrar su interfaz flotante.

Este acceso se utiliza exclusivamente para mostrar el overlay.

La extensión no recopila, almacena ni transmite:

  • el historial de navegación;
  • las URL visitadas;
  • el texto de las páginas;
  • imágenes;
  • formularios;
  • mensajes;
  • pulsaciones de teclado;
  • contenido introducido por el usuario;
  • otros contenidos de las páginas web visitadas.

La información de las páginas sobre las que aparece el overlay no se utiliza para publicidad, análisis ni creación de perfiles.

8. Seguridad

Las comunicaciones entre Position Overlay y los servicios externos necesarios para su funcionamiento se realizan mediante conexiones HTTPS.

La extensión limita el tratamiento de información de autenticación y financiera a lo estrictamente necesario para proporcionar las funcionalidades visibles al usuario.

El usuario es responsable de proteger sus credenciales API de Bitunix y se recomienda utilizar únicamente los permisos de API necesarios para el funcionamiento de Position Overlay.

9. Conservación y eliminación de datos

Las credenciales API y las preferencias almacenadas localmente permanecen en el navegador mientras sean necesarias para utilizar la extensión o hasta que el usuario las elimine.

El usuario puede eliminar los datos almacenados por Position Overlay eliminando la configuración correspondiente o desinstalando la extensión de Chrome.

Position Overlay no mantiene una copia independiente de estos datos en servidores operados por el desarrollador.

10. Uso limitado de los datos

Los datos procesados por Position Overlay se utilizan únicamente para proporcionar y mantener las funcionalidades visibles y declaradas de la extensión.

Los datos de autenticación y la información financiera no se utilizan ni transfieren para:

  • publicidad personalizada;
  • publicidad basada en intereses;
  • retargeting;
  • creación de perfiles comerciales;
  • venta de datos;
  • fines no relacionados con la funcionalidad principal de la extensión.

11. Servicios de terceros

Position Overlay utiliza la API de Bitunix para obtener la información de cuenta y posiciones solicitada por el usuario.

Las solicitudes enviadas a Bitunix y la información tratada por sus servicios están sujetas también a las condiciones y políticas de privacidad de Bitunix.

Position Overlay es un proyecto independiente y no está afiliado, patrocinado, respaldado ni desarrollado por Bitunix.

12. Cambios en esta política de privacidad

Esta política podrá actualizarse cuando cambie el funcionamiento de Position Overlay, los datos procesados, los servicios utilizados o los requisitos legales aplicables.

La fecha de la última actualización se mostrará siempre al principio de esta página.
