Política de Privacidad — Bitunix Positions Overlay

Última actualización: 29 de septiembre de 2026

Bitunix Positions Overlay utiliza los datos proporcionados por el usuario exclusivamente para ofrecer las funcionalidades de la extensión.

Datos procesados

La extensión puede procesar credenciales de API de Bitunix necesarias para consultar información de la cuenta del usuario, así como información financiera relacionada con posiciones, margen, PnL, niveles de entrada, Take Profit y Stop Loss.

Uso de las credenciales de Bitunix

Las credenciales proporcionadas por el usuario se utilizan exclusivamente para realizar solicitudes a la API de Bitunix necesarias para el funcionamiento de la extensión.

Venta, publicidad y uso comercial de datos

La extensión no vende, alquila ni utiliza los datos del usuario con fines publicitarios.

Datos de navegación

La extensión no recopila el historial de navegación, el contenido de las páginas visitadas, la ubicación, las comunicaciones personales ni la actividad del usuario en los sitios web.

Almacenamiento local

La configuración de la extensión y las credenciales necesarias para su funcionamiento se almacenan localmente en el navegador mediante las APIs de almacenamiento de Chrome, salvo que se indique expresamente lo contrario.

Comunicación con Bitunix

La extensión se comunica con los servicios de Bitunix para obtener los datos necesarios para mostrar posiciones y otra información relacionada con la cuenta del usuario.

Los datos obtenidos de Bitunix se utilizan únicamente para proporcionar las funcionalidades visibles de la extensión.

Eliminación de datos

El usuario puede eliminar los datos almacenados por la extensión desinstalándola o eliminando su configuración almacenada.

Relación con Bitunix

Esta extensión es un proyecto independiente y no está afiliada, respaldada ni desarrollada por Bitunix.
